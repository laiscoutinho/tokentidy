# Exemplos

> 🇺🇸 Para ler este arquivo em inglês, [clique aqui](../examples.md).

Execuções reais de cada comando, da primeira análise até o CI. Todas as saídas abaixo foram copiadas do TokenTidy `0.0.9`. Para o significado de cada opção, veja [Comandos](commands.md).

## De valores fixos a tokens

Um projeto pequeno:

```
shop/
├── package.json
└── src/
    ├── index.html
    ├── theme/theme.css
    └── components/
        ├── Button.tsx
        └── Card.css
```

`src/theme/theme.css` já tem um token, escrito à mão:

```css
:root {
  --brand: #4f46e5;
}
```

`src/components/Card.css` tem valores fixos, e um que a equipe quer manter:

```css
.card {
  color: #4f46e5;
  background: #FFF;
  padding: 16px;
  border-radius: 8px;
}

.card-title {
  color: #111827;
  margin-bottom: 16px;
  /* tokentidy-ignore-next-line spacing/hardcoded -- matches the print layout */
  margin-top: 13px;
}
```

`src/components/Button.tsx` tem os mesmos valores em um estilo inline:

```tsx
export function Button() {
  return <button style={{ background: 'white', padding: 16, borderRadius: 8, color: '#111827' }}>Buy</button>;
}
```

`src/index.html`:

```html
<!doctype html>
<p style="color: #111827; margin: 13px">Hello</p>
```

### 1. Veja o que está fixo no código

```bash
npx tokentidy check
```

```
src/components/Button.tsx:2:57	violation	spacing/hardcoded	padding	16
src/components/Button.tsx:2:75	violation	radius/hardcoded	border-radius	8
src/components/Button.tsx:2:86	violation	color/hardcoded	color	#111827
src/components/Card.css:2:10	violation	color/hardcoded	color	#4f46e5
src/components/Card.css:3:15	violation	color/hardcoded	background	#FFF
src/components/Card.css:4:12	violation	spacing/hardcoded	padding	16px

```

O código de saída é `1`, porque há violações. Repare que `margin-top: 13px` não aparece: o comentário acima dele mantém o valor de propósito.

### 2. Crie os tokens

```bash
npx tokentidy generate
```

```
design-tokens/tokens.tokens.json
design-tokens/tokens.css
4 new tokens, 0 kept, 0 semantic aliases
1 values already have a token in the project:
  #4f46e5	--brand	src/theme/theme.css:2 (1 use)
1 values used fewer than 2 times were not turned into tokens
diagnosis	color	3 values, 3 tokens, 100% of uses on a token
diagnosis	spacing	2 values, 1 token, 75% of uses on a token
diagnosis	radius	1 value, 1 token, 100% of uses on a token
suggestion	spacing	13px is off the 4px grid (nearest: 12px or 16px)
```

O que aconteceu com cada valor:

- `#FFF` e `white` são a mesma cor, então viraram um token só.
- `16px` no CSS e `16` no JSX são o mesmo tamanho, assim como `8px` e `8`.
- `#4f46e5` não ganhou token novo, porque `--brand` já tem esse valor.
- `13px` não ganhou token: fora da linha ignorada, ele é usado uma vez só.

`design-tokens/tokens.css`:

```css
/* Generated by TokenTidy from tokens.tokens.json. Edit the JSON and run `tokentidy generate` again. */
:root {
  /* color */
  --color-gray-950: #111827;
  --color-white: #ffffff;

  /* spacing */
  --spacing-4: 16px;

  /* radius */
  --radius-lg: 8px;
}
```

### 3. Veja a troca antes de aplicar

```bash
npx tokentidy fix --dry-run
```

```diff
@@ -1,3 +1,3 @@

 }

+++ b/src/components/Card.css
@@ -1,13 +1,13 @@

-  color: #4f46e5;
-  background: #FFF;
-  padding: 16px;
-  border-radius: 8px;
+  color: var(--brand);
+  background: var(--color-white);
+  padding: var(--spacing-4);
+  border-radius: var(--radius-lg);

-  color: #111827;
-  margin-bottom: 16px;
+  color: var(--color-gray-950);

--- a/src/index.html

@@ -1,2 +1,2 @@
```

Nada foi gravado ainda. O `--brand`, escrito à mão, teve preferência, e os números do JSX viraram strings.

### 4. Aplique

```bash
npx tokentidy fix
```

```
src/components/Button.tsx
src/components/Card.css
src/index.html
11 values replaced in 3 files; 0 skipped; 1 without a token; 1 violation remains
Generated tokens are used as var(); make sure the app loads design-tokens/tokens.css (import it in the global stylesheet or add it to the build)
```

O código de saída é `1`, porque sobrou uma violação: `margin: 13px`, que não tem token. **O `fix` não carrega os tokens para você:** importe `design-tokens/tokens.css` no estilo global, ou os `var()` não vão funcionar.

### 5. Verifique de novo

```bash
npx tokentidy check
```

```
src/index.html:2:49	violation	spacing/hardcoded	margin	13px
1 violation, 0 review in 1 file; 1 ignored by comment
```

Agora a decisão é sua: manter com um [comentário de ignorar](ignore-comments.md), ou trocar por um valor que o projeto já usa.

## SCSS: valores necessários na compilação

O Sass roda antes do navegador, então não consegue usar `var()` dentro das funções dele nem em `@media`. Nesses lugares, o `fix` escreve a variável Sass e adiciona o import:

```scss
.a { background: darken(#4f46e5, 10%); padding: 16px; }
.b { background: #4f46e5; padding: 16px; }
@media (min-width: 768px) { .c { width: 100%; } }
@media (min-width: 768px) { .d { width: 50%; } }
```

Depois de `npx tokentidy generate`, o `npx tokentidy fix --dry-run` mostra:

```diff
-.a { background: darken(#4f46e5, 10%); padding: 16px; }
-.b { background: #4f46e5; padding: 16px; }
-@media (min-width: 768px) { .c { width: 100%; } }
-@media (min-width: 768px) { .d { width: 50%; } }
+@use '../design-tokens/tokens' as *;
+.a { background: darken($color-indigo-600, 10%); padding: var(--spacing-4); }
+.b { background: var(--color-indigo-600); padding: var(--spacing-4); }
+@media (min-width: $breakpoint-md) { .c { width: 100%; } }
+@media (min-width: $breakpoint-md) { .d { width: 50%; } }
```

## Angular: bindings e templates

```ts
@Component({ selector: 'app-list', templateUrl: './list.component.html', styles: `.l { gap: 16px; color: #111827; }` })
export class ListComponent {}
```

```html
<ul [style.padding.px]="16" [ngStyle]="{'margin.px': 16, color: '#111827'}" style="color: #111827"></ul>
```

A unidade sai do nome do binding, porque o token já a inclui:

```diff
-<ul [style.padding.px]="16" [ngStyle]="{'margin.px': 16, color: '#111827'}" style="color: #111827"></ul>
+<ul [style.padding]="'var(--spacing-4)'" [ngStyle]="{'margin': 'var(--spacing-4)', color: 'var(--color-gray-950)'}" style="color: var(--color-gray-950)"></ul>
```

```diff
-@Component({ selector: 'app-list', templateUrl: './list.component.html', styles: `.l { gap: 16px; color: #111827; }` })
+@Component({ selector: 'app-list', templateUrl: './list.component.html', styles: `.l { gap: var(--spacing-4); color: var(--color-gray-950); }` })
```

## Rodando o `generate` de novo

Quando já existem tokens, o `generate` precisa de uma decisão. Fora de um terminal, ele para com o código de saída `2` em vez de esperar uma resposta:

```bash
npx tokentidy generate --extend   # mantém os nomes, adiciona o que é novo
npx tokentidy generate --new      # esquece os nomes gerados e recomeça
```

```
0 new tokens, 4 kept, 0 semantic aliases
```

No dia a dia, use `--extend`: os nomes que você já usa no código continuam os mesmos.

## Escolhendo limites e pastas

```bash
npx tokentidy generate --min-occurrences 3   # só valores usados 3+ vezes
npx tokentidy generate --out src/tokens      # outra pasta dentro do projeto
npx tokentidy fix --tokens src/tokens        # o fix lendo dessa pasta
```

As mesmas escolhas podem ficar no `tokentidy.config.json` ([Configuração](configuration.md)):

```json
{ "minOccurrences": 3, "gridBase": 8, "output": "tokens" }
```

Com esse arquivo, o projeto de exemplo fica com dois tokens. O `gridBase` também muda os nomes: `16px` agora é `--spacing-2`, dois passos de 8px.

## Trabalhando só em parte do projeto

```bash
npx tokentidy check src/components            # uma pasta
npx tokentidy check src/Card.css src/App.tsx  # arquivos específicos
npx tokentidy fix src/components --dry-run    # troca só aqui
```

O resultado pode ser diferente de uma execução completa: veja [Analisando parte de um projeto](check.md#analisando-parte-de-um-projeto). Para a resposta final, analise o projeto inteiro.

## Usando o resultado em scripts

Os dados vão para a saída padrão e o resumo para a saída de erro, então os pipes recebem só os dados.

Contar os valores por regra:

```bash
npx tokentidy check 2>/dev/null | cut -f3 | sort | uniq -c | sort -rn
```

```
      6 color/hardcoded
      4 spacing/hardcoded
      2 radius/hardcoded
```

Listar as cores com o [`jq`](https://jqlang.org/):

```bash
npx tokentidy check --json 2>/dev/null | jq -r '.findings[] | select(.type == "color") | "\(.file):\(.line) \(.value)"'
```

```
src/components/Button.tsx:2 white
src/components/Button.tsx:2 #111827
src/components/Card.css:2 #4f46e5
src/components/Card.css:3 #FFF
src/components/Card.css:9 #111827
src/index.html:2 #111827
```
